# 版本 2.0.1 — 废弃并彻底移除 SDXL ConvRot NVFP4 支持

本次发布严格遵循上游 [Hybrid-Sensitivity-Weighted-Quantization (HSWQ)](https://github.com/ussoewwin/Hybrid-Sensitivity-Weighted-Quantization) 与 [ComfyUI-HSWQ-Loader-and-Tools](https://github.com/ussoewwin/ComfyUI-HSWQ-Loader-and-Tools) 生态系统的最新技术规范，在 Stable-Diffusion-WebUI-Forge-Nunchaku 中正式废弃并彻底移除了对 **SDXL ConvRot NVFP4** 的所有支持与文档说明。

---

## 1. 概述

| 项目 | 详情 |
|---|---|
| **影响范围** | SDXL（包括 Stable Diffusion XL 1.0、Illustrious-XL、Animagine-XL 等架构） |
| **废弃格式** | **SDXL ConvRot NVFP4**（采用模拟/原生 NVFP4 Scale 的 4-bit FP4 权重半精度量化） |
| **标准规范** | 严格仅支持 **ConvRot INT8 (逆向混合模式 / reverse hybrid)**（`int8` / `int8 (fp16 LoRA)`） |
| **核心技术根因** | 确定性潜在轨迹发散：4-bit 精度从根本上无法在 SDXL 高容量 Cross-Attention UNet 中维持潜在轨迹保真度（余弦相似度 < 0.90，频繁出现轨迹分叉与崩溃） |
| **实测认知突破** | 传统像素级解码 SSIM (~0.95) 纯属 VAE 滤波平滑的假象（VAE 掩蔽陷阱），掩盖了潜空间分布的灾难性破坏 |
| **上游完全同步** | 彻底同步 HSWQ v2.0+ 规范，移除废弃的 Loader 代码分支并清理全部文档说明 |

## 2. 技术背景与根本原因分析

### 2.1 潜空间轨迹发散 vs. 解码 SSIM 假象（VAE 掩蔽陷阱）
在传统的扩散模型量化基准测试中，学术界与工程界通常将生成的潜变量（latent）解码到像素空间，并与未量化的 FP16 基准图像计算结构相似度（SSIM）或峰值信噪比（PSNR）。

在这一传统像素空间评估下，SDXL NVFP4 曾表现出看似可接受的 SSIM 分数（~0.94 - 0.95）。然而，通过采用 **确定性 25-seed 潜空间轨迹对比**（`sdxl/diag_impact_sdxl.py` / `benchmark_sdxl_int8.md`）进行微观实测，揭示了一个致命的技术盲区：
- **VAE 掩蔽陷阱（The VAE Masking Illusion）**：SDXL VAE 解码器本质上是一个强力的非线性低通滤波器与语义重建网络。潜空间中的严重分布崩溃与结构畸变在解码过程中被人工滤平并强行平滑，制造了图像质量合格的假象。
- **潜空间的真实崩塌**：当直接测量每一步潜张量的轨迹余弦相似度：
  $$\text{Cosine}(z_t^{\text{quant}}, z_t^{\text{fp16}}) = \frac{\langle z_t^{\text{quant}}, z_t^{\text{fp16}} \rangle}{\|z_t^{\text{quant}}\|_2 \|z_t^{\text{fp16}}\|_2}$$
  SDXL NVFP4 模型的最终步余弦相似度无一例外无法达到生产门禁线（$\ge 0.95$）。在多 Seed 评测中，平均最终余弦相似度跌破 $0.90$，并伴随极高的轨迹分叉率（Latent Bifurcation，即去噪路径直接偏离到完全错误且扭曲的语义盆地）。

### 2.2 4-Bit 精度下 SDXL Cross-Attention UNet 的脆弱性
SDXL 独特的架构特征加剧了 4-bit 浮点量化的失真：
1. **Cross-Attention 层的高动态范围与峰度**：SDXL 采用双 Text Encoder（CLIP ViT-L 与 OpenCLIP ViT-bigG）向深层 Cross-Attention 模块注入 2048 维度的 Pooled 与 Sequence 嵌入。其中段及深层模块中的投影矩阵（`to_q`, `to_k`, `to_v`, `to_out.0`）表现出极端的数据峰度。无论是均匀量化还是分块 4-bit（E2M1 NVFP4）量化，引入的量化噪声均大幅超出了 Attention Score Softmax 的误差容限。
2. **非线性误差级联放大效应**：扩散过程是一个迭代动力学系统。不同于自回归 LLM 的单向单步推演，早期去噪步中由 UNet 量化噪声引发的微小扰动会在后续逆扩散步中呈指数级级联放大，导致去噪轨迹不可逆地偏航脱轨。

## 3. SDXL 精度策略：ConvRot INT8 逆向混合标准

为保证无可挑剔的生成画质并实现潜空间轨迹零分叉，SDXL 的量化标准全面统一为 **ConvRot INT8 (逆向混合模式 / reverse hybrid)**。

### 3.1 逆向混合机制（Reverse Hybrid）
与传统的“全网量化后挑出少量敏感层保护”不同，HSWQ 逆向混合方法直接从完整的 FP16 基准出发，通过轨迹影响度升序筛选量化层：
1. **采样轨迹影响度实测**：在生产级采样器（Euler、DPM++ 2M Karras）的实际运行轨迹上，逐层测量各候选层量化为 ConvRot INT8 后的潜在轨迹扰动。
2. **升序影响度量化**：仅将影响度最低的下位 $K$ 个层打包为 FULL ConvRot INT8（`int8_tensorwise`），所有敏感层、结构层及 Cross-Attention 关键层 100% 保持 FP16。
3. **生产门禁要求**：量化模型必须通过确定性 25-seed 潜空间轨迹门禁评测：
   - **平均最终潜空间余弦相似度**：$\ge 0.95$
   - **轨迹分叉数**：**0 / 25 seeds**（完全零结构性分叉）

### 3.2 方案对比矩阵：SDXL 各量化方案实测

| 精度格式 | 位宽 | 潜空间轨迹余弦相似度 | 25-Seed 轨迹分叉率 | 生产级状态 |
|---|---|---|---|---|
| **FP16 / BF16** | 16-bit | 1.0000（基准） | 0 / 25 | 基准参考 |
| **ConvRot INT8 (逆向混合)** | 8-bit hybrid | **$\ge 0.950$（均值 0.96+）** | **0 / 25 (0%)** | **生产级标准** |
| **Native 全 INT8** | 8-bit uniform | 0.935 - 0.945 | 3 - 5 / 25 (12-20%) | 已废弃 / 不合规 |
| **ConvRot NVFP4** | 4-bit | **< 0.900** | **12+ / 25 (> 48%)** | **已正式废弃并移除** |

## 4. 仓库与运行时改动

### 4.1 文档与规格清理
- **`README.md` 与 `zhmd/README.md`**：彻底移除了 Forge 核心仓库及内置 `modules/ComfyUI-HSWQ-Loader-and-Tools` 中所有关于 SDXL NVFP4 的特性介绍、支持列表与架构参数说明。

### 4.2 WebUI Forge 模型加载与调度
- 通过 Forge 与 ComfyUI-HSWQ-Loader 加载的 SDXL 模型仅走 FP16 或 ConvRot INT8 调度路径。
- 清除了针对 SDXL 架构冗余的 NVFP4 Scale 模拟与分支兜底处理逻辑。
